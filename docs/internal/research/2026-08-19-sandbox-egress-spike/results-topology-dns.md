```sh

```

The proxy had both `s7a-int` and `s7a-egress`. The internal network reported `Internal=true`. This proves the proxy was dual-homed while its command-facing network was internal.

Docker 29.4.0 does not expose `.IPv6` in the `docker info` Go template on this host. The daemon advertised an IPv6 default address pool, but it did not assign or route IPv6 on these networks. No IPv6 route off the internal network existed.
