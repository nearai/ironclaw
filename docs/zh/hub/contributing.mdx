## 来源分级

新提交以 **New**（未验证）进入。审核后可能升级为 **Verified** 或 **Trusted**。仅由 IronClaw 团队维护的包标记为 **Official**。各等级的定义见[来源分级](/hub/overview)。

---

## 提交前

你可以发布两种类型的包：**Tools**（WASM 二进制 + capability manifest）和 **Skills**（SKILL.md）。

- 如果要创建 WASM 扩展，请参考[构建工具](/extensions/building-a-tool)指南。
- 关于 SKILL.md 格式和激活模式，请参考[Skills](/capabilities/skills)参考文档。
- 提交前在本地测试你的包。
- 保持描述清晰——这是用户和代理在目录中发现你作品的方式。
