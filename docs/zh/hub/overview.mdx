## 目录内容

IronHub 分发两种类型的包：

| 类型             | 内容                                   | 获得的功能                                  |
|------------------|----------------------------------------|---------------------------------------------|
| Extension（工具）| WASM 二进制 + capability manifest（TOML）| 代理可在运行时调用的新工具                   |
| Skill（技能）    | SKILL.md                               | 代理按需加载的提示指令                       |

---

## 来源分级

每个目录条目都带有来源标签，说明其审核情况：

| 等级             | 描述                                                                                                                               |
|------------------|------------------------------------------------------------------------------------------------------------------------------------|
| **Official**     | 由 IronClaw 团队发布和维护。                                                                                                       |
| **Trusted**      | 经 IronClaw 团队审核，确认安全性和正确性。                                                                                          |
| **Verified**     | 发布者身份已确认，但包未经审计。                                                                                                    |
| **Private**      | 限定于特定组织或团队——不公开列出。                                                                                                 |
| **New**          | 社区提交，尚未审核。安装需运营商明确确认——代理无法自主安装此类包。                                                                   |
