What this explores. The whole OOBE arc in one place. First run fills the two moments the PR #6994 prototype skips — the cold-start (nothing yet) and the first "Done for you" card appearing. Thread and Plan are the two in-thread concepts already prototyped in code: the inline calendar-reschedule rich-preview and the batched-approval Plan card. All three run on the real --v2-* tokens.

Built in PR #6994 (presentational, mock data — not yet merged to main): the AutomationCarousel + AutomationTaskCard, CalendarRescheduleCard, PlanCard, the shared TaskActionBar (Approve/Modify/Cancel · Modify/Revert), and the agent-mode pill. Genuinely Shipped on main: the branded NearProcessIndicator (#6901) and the AuthRequired connector the connect row reuses.

Needs a new payload (issue #6993): the empty / anticipatory / reveal states and the durable task lifecycle behind Thread and Plan — the AutomationTaskAutomated / PlanUpdate projection events (see AUTOMATION-TASKS-CONTRACT.md §§2–7).
