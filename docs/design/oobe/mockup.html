What this explores. The automation surfaces from PR #6994 all assume automations already exist. This mockup fills the two first-run moments that leaves open: the cold-start screen (nothing yet) and the first automation appearing. Toggle Invite vs Coach to compare a minimal cold start against an anticipatory one that previews the concept with ghost cards.

Shipped today (PR #6994, presentational, mock data): the AutomationCarousel + AutomationTaskCard + TaskActionBar, the agent-mode pill (mode-selector.tsx), and the endpoint-shaped data seam. Connect uses the existing AuthRequired connector card. The NearProcessIndicator is on main (#6901).

Needs a new payload (issue #6993): the carousel return nulls with no tasks today, so the empty, anticipatory ("working on your first automation"), and reveal states all need the projection to report task lifecycle — the AutomationTaskAutomated event drives the first-card reveal (see AUTOMATION-TASKS-CONTRACT.md §§2–7). The ghost/Coach state is a net-new onboarding surface.
