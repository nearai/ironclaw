The following skills are available for use with builtin.skill_activate.
A skill is a packaged set of instructions someone has already written for a particular kind of task. When the task at hand is one a listed skill covers, activate it FIRST and follow its instructions instead of your own default approach — that is the point, since a listed skill encodes decisions you would otherwise have to rediscover.
Use exact listed names. Choose the smallest relevant set, with at most eight active skills total per run; large skills may reduce that number.
Activate a skill only when the task EXPLICITLY involves what its description names — a file format the task actually uses, a domain the task actually is about. If the task never mentions it, do not activate it even when it looks adjacent: an adjacent skill spends the budget and its instructions pull you off-task. If activation reports an ambiguous name, do not guess; explain the conflict.
