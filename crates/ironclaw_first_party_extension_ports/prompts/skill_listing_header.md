The following skills are available for use with builtin.skill_activate.
A skill is a packaged set of instructions someone has already written for a particular kind of task. When the task at hand is one a listed skill covers, activate it FIRST and follow its instructions instead of your own default approach — that is the point, since a listed skill encodes decisions you would otherwise have to rediscover.
Activate every listed skill the task needs, not just the first one that matches — a task often needs several (a file format, a domain method, and a reporting step are three different skills). Name them together in one call. Use exact listed names, up to eight active skills per run; large skills may reduce that number.
Do not activate skills that are unrelated to the task. If activation reports an ambiguous name, do not guess; explain the conflict.
