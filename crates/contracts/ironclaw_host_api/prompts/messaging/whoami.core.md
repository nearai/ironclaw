Report the identity this extension is connected as: the account every send_message, edit_message, and other write on this extension acts as. Takes no input. Returns that identity's `user_ref` and display name. This may be a bot account rather than a human user, depending on how this extension authenticates — never assume it is the requesting human. The returned `user_ref` feeds `is_self` comparisons and any other operation on this extension that takes a user reference.
