Look up a single conversation's details on this extension. `conversation` is an opaque conversation ref belonging to this extension — from this extension's discovery operations, where available, or a conversation ref the channel context provides, or an earlier message_ref; never invented, never reused across extensions. Returns that conversation's kind (`dm`, `group_dm`, `channel`, or `other`), display name, membership, and, for a dm, the counterpart's `user_ref`, for use in this extension's other operations.
