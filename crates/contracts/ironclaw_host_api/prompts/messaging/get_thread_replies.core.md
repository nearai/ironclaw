Read the replies in a message thread on this extension. `conversation` is an opaque conversation ref belonging to this extension, and `thread` is an opaque thread anchor from a message or message_ref — obtain both from this extension's own operations; never invent either and never reuse one from a different extension. Results are oldest-first (chronological); optional `limit`/`cursor` page them, and an opaque `next_cursor` continues where this call left off. Returns each reply's `message_ref`, author, text, and `is_self` — true when this extension's connected identity authored the reply, so attribute it to the requester.
