Look up a person's profile on this extension. `user_ref` is an opaque user id — from this extension's discovery operations, where available, or a user ref the channel context provides, or an earlier result; never derived from a conversation id. Returns display name, real name, status, timezone, and whether the account is a bot; this same `user_ref` feeds open_dm, where available, and any other operation on this extension that takes a user reference.
