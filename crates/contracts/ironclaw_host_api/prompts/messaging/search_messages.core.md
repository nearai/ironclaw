Find messages by content anywhere on this extension, when you do not already know which conversation holds them. `query` is the search text. Optional `sort` is `relevance` (the default vendor ranking, which may lag the newest messages) or `timestamp` (newest first); use `timestamp` for latest/most-recent questions. Use this extension's get_conversation_history, where available, instead when you already hold a `conversation` ref and want its recent messages in order. Optional `limit`/`cursor` page the results, and an opaque `next_cursor` continues where this call left off. Returns each match's `message_ref`, author, text, an optional `total` count when the vendor reports one, and `is_self` — true when this extension's connected account authored the message; that account may be a bot and must not be assumed to be the requesting human.
