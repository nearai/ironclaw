Open, or fetch the existing, direct-message conversation with a person on this extension. `user_ref` is an opaque user id — from this extension's discovery operations, where available, or a user ref the channel context provides, or an earlier result; never derived from a conversation id. Returns a `conversation` ref for that DM: use it with send_message and this extension's other conversation-scoped operations, where available. This is how a name like "DM Sergey" becomes a usable ref when no conversation ref exists yet.
