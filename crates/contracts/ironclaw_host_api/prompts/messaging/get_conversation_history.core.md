Read recent messages from a conversation on this extension, newest-first. `conversation` is an opaque conversation ref belonging to this extension — from this extension's discovery operations, where available, or a conversation ref the channel context provides, or an earlier message_ref; never invented, never reused across extensions. Use this extension's search_messages, where available, to find a message by content across conversations. Optional `limit`/`cursor` page the results, and an opaque `next_cursor` continues where this call left off. History excludes thread replies — a message's `thread.reply_count` above zero signals a thread; fetch it with this extension's get_thread_replies, where available. Returns each message's `message_ref`, author, text, and `is_self` — true when this extension's connected identity authored the message, so attribute it to the requester.
