List conversations on this extension visible to its connected identity. Optional `kinds` filters results to `dm`, `group_dm`, `channel`, or `other`; omit it to return every kind. Optional `limit`/`cursor` page the results, and an opaque `next_cursor` continues where this call left off. Returns each conversation's `conversation` ref plus its kind and display name — use the ref with send_message, get_conversation_history, and this extension's other conversation-scoped operations where available.
