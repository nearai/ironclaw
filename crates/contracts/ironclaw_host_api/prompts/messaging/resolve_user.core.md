Search for people on this extension by name, handle, or similar text. `query` is the search text; optional `limit`/`cursor` page the results, and an opaque `next_cursor` continues where this call left off. Returns matching people as a `user_ref` plus display name; feed a match's `user_ref` into open_dm, get_user_info, or any other operation on this extension that takes a user reference, where available.
