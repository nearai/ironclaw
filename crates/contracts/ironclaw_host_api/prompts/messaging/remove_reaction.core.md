Remove a previously added emoji reaction from a message on this extension, as its connected account. `message_ref` must be the exact object returned by a prior send or read on this extension — never invent one and never reuse a ref from a different extension. Optional `emoji` is this vendor's emoji token, a name or a unicode character; omit it when the schema/addendum says the vendor can remove the connected account's reaction(s) without naming one. Returns the `message_ref` always, and `emoji` too when known, as confirmation that the reaction was removed.
