Fetch a single message by reference on this extension. `message_ref` must be the exact object returned by a prior send or read on this extension — never invent one and never reuse a ref from a different extension. Returns that message's author, text, timestamp, thread info, and `is_self` — true when this extension's connected identity authored the message, so attribute it to the requester — so you can inspect one message without reading its whole conversation history.
