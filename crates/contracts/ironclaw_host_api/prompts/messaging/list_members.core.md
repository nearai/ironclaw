List the members of a conversation on this extension. `conversation` is an opaque conversation ref belonging to this extension — from this extension's discovery operations, where available, or a conversation ref the channel context provides, or an earlier message_ref; never invented, never reused across extensions. Optional `limit`/`cursor` page the results, and an opaque `next_cursor` continues where this call left off. Returns each member as a `user_ref` plus display name; feed a member's `user_ref` into open_dm, get_user_info, or any other operation on this extension that takes a user reference, where available.
